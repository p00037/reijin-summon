# 通常ユニット・召喚獣パラメータ調整設計

## 目的

通常ユニットと召喚獣の移動時間を指定値へ合わせ、召喚獣のHP・攻撃・自然減少をカウント単位で調整する。本仕様では `1C = 1秒` とする。

## 召喚獣HP

召喚獣の最大HPは次の式で算出する。

`1750 + 60 × (召喚面積 ÷ 戦場全体面積 × 100)`

- 面積0%: 1,750 HP
- 面積5%: 2,050 HP
- 面積100%: 7,750 HP

召喚面積は召喚士と完成済みエレメントの凸包面積、戦場全体面積は `battlefieldMin` と `battlefieldMax` から求める。

## 召喚獣の攻撃

- 攻撃間隔は2Cとする。
- 通常ユニットと敵召喚獣への基本攻撃力は1回99とする。
- 敵召喚士への攻撃力は1回300とする。
- 現在の挙動を維持し、攻撃時点で接触している全対象へ同時にダメージを与える。
- 攻撃タイマーは通常ユニットと同様に経過時間で管理し、攻撃後に2Cへ戻す。
- 攻撃対象がいない間もタイマーを進める。

## HP自然減少

召喚獣のHPは毎秒120減少する。フレーム時間に依存しないよう `120 × deltaSeconds` を減算する。自然減少でHPが0になったフレームでは攻撃しない。

## 移動速度

召喚士間の距離8.2を基準に、指定所要時間から次の速度を設定する。

| 種類 | 速度 | 召喚士間の所要時間 |
| --- | ---: | ---: |
| ラファエル（召喚獣） | `8.2 / 12`（約0.683/C） | 約12C |
| キーパー（Melee） | `8.2 / 40`（0.205/C） | 約40C |
| シーカー（Speed） | `8.2 / 22`（約0.373/C） | 約22C |
| マスター（Ranged） | `8.2 / 32`（約0.256/C） | 約32C |

接触中の既存速度低下倍率は変更しない。

## データ構造

`SummonedUnitState` に攻撃間隔と攻撃タイマー、召喚士専用攻撃力を保持する。召喚獣のパラメータは `BattleConfig` に明示的な設定値として持たせ、生成処理とテストから参照する。

## テスト

- 面積0%、5%、100%でHPがそれぞれ1,750、2,050、7,750になることを確認する。
- 2C未満では攻撃せず、2C到達時に通常対象へ99、召喚士へ300ダメージを与えることを確認する。
- 1CでHPが120減少することを確認する。
- 各ユニットの速度と、召喚獣の速度が指定値であることを確認する。
- 型チェックと全テストを実行する。
