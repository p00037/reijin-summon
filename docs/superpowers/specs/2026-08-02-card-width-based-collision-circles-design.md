# カード横幅基準の当たり判定円 設計

## 目的

通常ユニットと召喚獣の当たり判定円を、それぞれのカード横幅を基準にした大きさへ変更する。円の直径はカード横幅の1.2倍とし、異なる対象同士は双方の当たり判定円が重なった時点で接触したものとして扱う。

カード枠、カード画像、HPバーなどの表示サイズは変更しない。

## 現状

- 戦場の画面幅515.2pxは、ワールド座標の横幅12.6に対応する。
- 通常ユニットのカード横幅は51.52pxである。
- 召喚獣のカード横幅は通常ユニットの1.3倍で、66.976pxである。
- 通常ユニットと召喚獣は共通の中心間距離しきい値 `contactSlowRadius = 0.54` を使用している。
- 通常ユニットの選択円は `contactSlowRadius` を画面座標へ変換して描画している。

## 当たり判定円

### 通常ユニット

- 直径: `51.52px × 1.2 = 61.824px`
- 画面上の半径: `30.912px`
- ワールド座標の半径: `30.912 ÷ (515.2 ÷ 12.6) = 0.756`

### 召喚獣

- 直径: `66.976px × 1.2 = 80.3712px`
- 画面上の半径: `40.1856px`
- ワールド座標の半径: `40.1856 ÷ (515.2 ÷ 12.6) = 0.9828`

## 設定

共通設定 `contactSlowRadius` を、対象種別が明確な次の2設定へ置き換える。

- `unitCollisionRadius = 0.756`
- `summonedUnitCollisionRadius = 0.9828`

ゲームルール層から画面描画設定を参照せず、算出済みのワールド座標値を `BattleConfig` で管理する。これにより、ルールと表示の依存方向を維持しながら、数値の意図を設定名で明確にする。

## 接触判定

通常ユニットと召喚獣同士の接触は、対象ごとの半径を加算した値と中心間距離を比較する。

| 組み合わせ | 接触する中心間距離 |
| --- | ---: |
| 通常ユニットと通常ユニット | `0.756 + 0.756 = 1.512` 以下 |
| 通常ユニットと召喚獣 | `0.756 + 0.9828 = 1.7388` 以下 |
| 召喚獣と召喚獣 | `0.9828 + 0.9828 = 1.9656` 以下 |

比較時は距離の二乗を使用してよい。境界上は接触として扱う。

接触判定は攻撃方向にかかわらず対称とし、通常ユニット側と召喚獣側のどちらから評価しても同じ結果になるよう、共通の半径加算関数へ集約する。

### エレメンタル・召喚士

エレメンタルと召喚士には今回新しい当たり判定円を設定せず、中心点として扱う。

- 通常ユニットとエレメンタル: `unitCollisionRadius` 以下
- 召喚獣とエレメンタル: `summonedUnitCollisionRadius` 以下
- 召喚獣と召喚士: `summonedUnitCollisionRadius` 以下

エレメンタルの配置判定、召喚士の回復範囲、通常ユニットの攻撃射程など、接触判定以外の距離設定は変更しない。

## 選択表示とクリック取得

- 通常ユニット選択時の黄色い円は `unitCollisionRadius` を画面座標へ変換して描画する。
- 標準の戦場表示では半径30.912px、直径61.824pxになる。
- クリックしてユニットを取得する半径 `selectionRadiusPx = 28` は変更しない。
- 召喚獣は現在選択対象ではないため、新しい選択円は追加しない。

## 対象外

- 通常ユニットと召喚獣のカード枠サイズ
- カード画像の表示サイズと配置
- HPバーのサイズと配置
- エレメンタルと召喚士の表示サイズ
- 通常ユニットの攻撃射程
- エレメンタルの配置間隔
- 召喚士の回復範囲

## テスト方針

- 既定設定が `unitCollisionRadius = 0.756` と `summonedUnitCollisionRadius = 0.9828` を返すことを検証する。
- 通常ユニット同士が中心間距離1.512で接触し、それを超えると接触しないことを検証する。
- 通常ユニットと召喚獣が中心間距離1.7388で、評価方向にかかわらず接触することを検証する。
- 召喚獣同士が中心間距離1.9656で接触し、それを超えると接触しないことを検証する。
- 通常ユニットとエレメンタルは0.756、召喚獣とエレメンタルおよび召喚士は0.9828を境界として接触することを検証する。
- 選択円が標準表示で半径30.912pxになり、カード横幅の1.2倍の直径になることを検証する。
- `selectionRadiusPx = 28`、カード表示寸法、HPバー配置が変更されていないことを既存テストで確認する。

## 完了条件

- 通常ユニットと召喚獣の当たり判定円の直径が、それぞれのカード横幅の1.2倍である。
- 通常ユニットと召喚獣同士は双方の半径を加算した対称な接触判定を使用する。
- エレメンタルと召喚士は中心点として扱われ、カード対象側の半径だけで接触判定する。
- 通常ユニットの選択円が新しい当たり判定円と一致する。
- クリック取得半径と対象外の表示・ルールに回帰がない。
