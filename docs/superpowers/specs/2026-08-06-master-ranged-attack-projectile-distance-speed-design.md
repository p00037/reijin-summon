# マスター遠距離攻撃の距離判定・弾速調整設計

## 目的

マスター（内部種別 `Ranged`）が近距離で攻撃した場合は魔法弾を表示せず、遠距離攻撃時だけ魔法弾を表示する。あわせて、魔法弾が対象へ飛ぶ速度を現在のおよそ半分にする。

本変更は表示演出に限定する。攻撃対象の選択、攻撃射程、ダメージ、攻撃間隔、ダメージ適用タイミングは変更しない。

## 距離別の表示仕様

攻撃イベントが持つ攻撃元と攻撃対象のワールド座標から、直線距離を求める。

| 攻撃者 | 攻撃距離 | 表示 |
| --- | ---: | --- |
| `Ranged` | `1.0` 以下 | 何も表示しない |
| `Ranged` | `1.0` 超 | 魔法弾を表示する |
| `Melee` / `Speed` | 任意 | 既存の白線を表示する |
| 攻撃者不明 | 任意 | 既存の白線を表示する |

境界値 `1.0` は近距離に含める。近距離の `Ranged` 攻撃では、魔法弾だけでなく既存の白線も表示しない。

## 弾速

遠距離の `Ranged` 攻撃で表示する魔法弾の移動時間を、現在の `250ms` から `500ms` へ変更する。始点・終点、直線移動、等速補間、回転、加算合成、表示寸法、描画深度、Tween完了時の破棄は変更しない。

移動距離によらず移動時間を `500ms` とする。ここでいう「速度を半分」は、現在の同じ始点・終点に対する移動時間を2倍にする意味とする。

## 構成

### BattleScene

`BattleScene` は、攻撃イベントのワールド座標から攻撃距離を計算する。その距離と、既存の画面座標へ変換した始点・終点を表示計算モジュールへ渡す。

距離は画面ピクセルでは判定しない。画面サイズやレイアウト変更によって近距離境界が変わらないよう、ゲーム内のワールド座標を使用する。

### 表示計算モジュール

`attackEffectPresentation` は、兵種、攻撃距離、画面上の始点・終点を受け取る。

返却する判別可能な表示種別へ `None` を追加し、次の順で判定する。

1. 攻撃者が `Ranged` 以外または不明なら `Line` を返す。
2. `Ranged` かつ攻撃距離が `1.0` 以下なら `None` を返す。
3. `Ranged` かつ攻撃距離が `1.0` 超なら `RangedProjectile` を返す。

`RangedProjectile.durationMs` は `500` とする。

`BattleScene` は `None` を受け取った場合、画像・Tween・白線のいずれも生成しない。

## データフロー

1. 戦闘処理が従来どおり攻撃イベントを生成し、ダメージを即時適用する。
2. `BattleScene` が攻撃元と対象のワールド座標から距離を計算する。
3. `BattleScene` が兵種、距離、画面座標を表示計算へ渡す。
4. 表示計算が `None`、`Line`、`RangedProjectile` のいずれかを返す。
5. `BattleScene` が返却種別に従って、非表示、白線、500msの魔法弾を描画する。

戦闘状態および攻撃イベントの型は変更しない。

## テスト

`rangedAttackPresentation.test.ts` で次を検証する。

- `Ranged` の攻撃距離が `1.0` の場合に `None` を返すこと。
- `Ranged` の攻撃距離が `1.0` 未満の場合に `None` を返すこと。
- `Ranged` の攻撃距離が `1.0` をわずかに超える場合に `RangedProjectile` を返すこと。
- 遠距離魔法弾の `durationMs` が `500` であること。
- `Melee`、`Speed`、攻撃者不明は距離にかかわらず `Line` を返すこと。
- 遠距離魔法弾の回転、表示寸法、描画深度など既存契約を維持すること。

実装後はクライアント全テスト、全体型チェック、全体ビルドを実行する。ローカル画面では、近距離のマスター攻撃にエフェクトが出ないこと、遠距離では従来の魔法弾が約500msで飛ぶこと、他兵種の白線が維持されることを確認する。

## 対象外

- 攻撃対象選択や攻撃可能距離の変更
- 接触判定、当たり判定、カードサイズの変更
- ダメージ、攻撃間隔、ダメージ適用タイミングの変更
- 距離に比例した可変弾速
- 近距離専用の別エフェクト追加
- 魔法弾画像、色、寸法、回転、合成方法の変更
