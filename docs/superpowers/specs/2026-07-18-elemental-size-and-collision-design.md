# エレメント縮小と当たり判定 設計書

## 仕様

- エレメント画像は44pxから22pxへ縮小する。
- 外周リング半径は18pxから9pxへ縮小する。
- HPバーの幅36pxと位置は変更しない。
- エレメント配置の重なり判定半径は0.45から0.225へ縮小する。
- エレメントへの接近減速判定は、通常ユニット同士の接触判定と分離し、半径0.225を用いる。
- 通常ユニット同士・召喚獣同士・リーダー接触の半径0.45は変更しない。

## 実装方針

`BattleConfig` に `elementalContactRadius` を追加し、既定値を0.225にする。エレメントの描画サイズは `BattleScene` の定数を更新する。エレメント配置判定とエレメント近接減速だけが新しい半径を参照する。

## テスト

- 既定の配置半径・エレメント接触半径が0.225であることを検証する。
- 通常ユニット接触半径が0.45のまま維持されることを検証する。
- 型チェック、全テスト、ビルドを実行する。
