# ユニット・召喚獣の当たり判定とHP表示調整の設計

## 目的

ユニットと召喚獣の接触判定を広げ、ユニットカード内の画像とHPバーの視認性を改善する。あわせて、画面上部の敵・味方HP表示と重複している召喚士直上のHPバーを廃止する。

## 変更内容

### 当たり判定

- 通常ユニットと召喚獣が使用する共通接触半径 `contactSlowRadius` を、現在の `0.45` から1.2倍の `0.54` へ変更する。
- 接触による攻撃開始と移動速度低下の判定に、新しい半径を適用する。
- エレメンタル専用の配置半径および接触半径は変更しない。
- 攻撃射程、画像サイズ、カード枠サイズは変更しない。

既存実装では通常ユニットと召喚獣の接触判定が `contactSlowRadius` を共有しているため、今回は設定値の変更だけで両者へ同じ倍率を適用する。ユニット用と召喚獣用の設定分離や、対象ごとの半径を加算する判定方式への変更は行わない。

### ユニットカード内の画像配置

- ユニット画像の表示幅と表示高さは維持する。
- カード枠の表示幅と表示高さも維持する。
- 画像中心をカード上端方向へ4px移動する。
- CPU側などカードが回転している場合も、画面上方向ではなくカード固有の上端方向へ移動する。
- 召喚獣画像の配置は変更しない。

カード内の余白計算と回転対応を維持するため、カード画像位置の計算へカード座標系の追加オフセットを渡せる形にする。

### HPバー配置

- 通常ユニットのHPバーを、現在の画面座標上の位置から下へ6px移動する。
- HPバーの幅、高さ、色、残HP比率の計算は変更しない。
- 召喚獣とエレメンタルのHPバー位置は変更しない。
- プレイヤーおよびCPUの召喚士直上に描画しているHPバーを削除する。
- 画面上部HUDの敵・味方HP表示は維持する。

## 影響するコンポーネント

- `battleConfig.ts`
  - 共通接触半径の既定値を `0.54` に変更する。
- `cardPresentation.ts`
  - カードの回転に追従する画像位置オフセットを表現する。
- `BattleScene.ts`
  - 通常ユニット画像へ4pxの上方向オフセットを適用する。
  - 通常ユニットHPバーを6px下へ移動する。
  - 召喚士直上のHPバー描画を削除する。
- 既存テスト
  - 接触半径、カード回転時の画像位置、HPバー表示位置、召喚士HPバーの非表示を検証する。

## テスト方針

- `createDefaultBattleConfig()` の `contactSlowRadius` が `0.54` であることを検証する。
- 距離が旧半径 `0.45` より大きく新半径 `0.54` 以下の敵に対して、通常ユニットと召喚獣の接触判定が成立することを検証する。
- ユニット画像がプレイヤー側とCPU側の双方でカード上端方向へ4px移動することを、純粋な位置計算関数で検証する。
- 通常ユニットHPバーのY座標が従来の `screen.y + 21` から `screen.y + 27` へ変更されることを検証する。
- 召喚士の戦場内HPバー用レイアウトが生成されないことを検証する。
- クライアント全体の型チェック、ユニットテスト、ビルドを実行する。

## 完了条件

- 通常ユニットと召喚獣の共通接触半径が、画像やカード枠を拡大せず `0.54` になる。
- 通常ユニット画像がカード上端方向へ4px移動する。
- 通常ユニットHPバーが画面下方向へ6px移動する。
- 召喚士直上のHPバーが表示されず、画面上部HUDの敵・味方HP表示は残る。
- 関連テスト、型チェック、クライアントビルドが成功する。
