# Speedユニット移動速度縮小 設計書

## 目的

Speedユニットの移動が速すぎるため、移動速度を現行値の2/3へ縮小する。通常ユニットの種類間にある移動速度の差は維持する。

## 表示・ゲーム仕様

- `Speed` の `moveSpeed` を `0.75` から `0.5` へ変更する。
- `Melee` の `0.5` と `Ranged` の `0.375` は変更しない。
- 召喚獣の移動速度はSpeedユニットの速度に `1.2` を掛けて算出する既存仕様を維持する。
- このため、新規召喚獣の移動速度は `0.9` から `0.6` へ変わる。
- 移動速度以外のHP、攻撃力、射程、攻撃間隔、接触時の減速倍率は変更しない。

## 実装方針

`battleConfig.ts` の既定 `statsByType.Speed.moveSpeed` だけを `0.5` に変更する。通常ユニットの移動処理と召喚獣の速度計算は既存設定を参照しているため、ロジックコードは変更しない。

## テスト

- 既定バトル状態のSpeedユニット速度が `0.5` であることを検証する。
- 召喚時に生成される召喚獣の速度が `0.6` であることを検証する。
- クライアントの型チェック、全テスト、プロダクションビルドを実行する。

## 対象外

- MeleeおよびRangedの移動速度変更
- 召喚獣速度の算出式変更
- 移動、戦闘、エレメンタル接触のロジック変更
