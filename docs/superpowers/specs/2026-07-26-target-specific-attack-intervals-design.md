# 対象種別別の攻撃間隔設計

## 目的

キーパー、シーカー、マスター、および召喚獣の攻撃間隔を、攻撃対象が召喚士か、それ以外かによって分ける。通常対象への攻撃頻度を高めながら、召喚士への攻撃頻度は指定された周期に維持する。本仕様では `1C = 1秒` とする。

## 攻撃間隔

### 通常ユニット

キーパー、シーカー、マスターの3兵種で共通して、次の攻撃間隔を使用する。

| 攻撃対象 | 攻撃間隔 |
| --- | ---: |
| 敵通常ユニット | 0.5C |
| 敵召喚獣 | 0.5C |
| 敵エレメント | 0.5C |
| 敵召喚士 | 1C |

### 召喚獣

| 攻撃対象 | 攻撃間隔 |
| --- | ---: |
| 敵通常ユニット | 0.5C |
| 敵召喚獣 | 0.5C |
| 敵エレメント | 0.5C |
| 敵召喚士 | 2C |

召喚獣から敵召喚士への攻撃間隔は、現在の2Cから変更しない。

## 独立タイマー

各攻撃者は、通常対象用と召喚士用の2つの攻撃タイマーを独立して保持する。

- `attackTimerSeconds` は通常ユニット、召喚獣、エレメントに対する攻撃タイマーとして維持する。
- `leaderAttackTimerSeconds` を召喚士に対する攻撃タイマーとして追加する。
- 両タイマーは、攻撃対象の有無にかかわらず各tickで0まで独立して減少する。
- 通常対象へ攻撃した場合は、通常対象用タイマーだけを通常対象用の攻撃間隔へ戻す。
- 召喚士へ攻撃した場合は、召喚士用タイマーだけを召喚士用の攻撃間隔へ戻す。
- 一方の攻撃は、もう一方のタイマーを変更しない。
- タイマーは0未満にしない。

攻撃者の生成時と通常ユニットの復活時には、両タイマーを0で初期化する。これにより、現在と同様に攻撃可能な対象へ初めて接触した時点では即座に最初の攻撃が可能となる。

## 通常ユニットの戦闘処理

通常ユニットは、既存どおり攻撃可能な対象から最も近い1体を選ぶ。選択対象の種別に応じて使用するタイマーを切り替える。

- 選択対象が召喚士の場合は、`leaderAttackTimerSeconds` が0のときだけ攻撃する。
- 選択対象が通常ユニット、召喚獣、またはエレメントの場合は、`attackTimerSeconds` が0のときだけ攻撃する。
- 攻撃対象が召喚士とそれ以外の間で切り替わっても、それぞれの残り時間を維持する。
- 攻撃力、射程、対象選択、対エレメント倍率、召喚士への直接攻撃倍率は変更しない。

通常ユニットは従来どおり1回の攻撃処理で選択した1対象だけを攻撃する。

## 召喚獣の戦闘処理

召喚獣は、既存どおり接触中の対象を同一tickで処理するが、召喚士と通常対象の攻撃判定を分離する。

- 接触中の敵通常ユニット、敵召喚獣、敵エレメントは、`attackTimerSeconds` が0のときに同時に攻撃する。
- 敵召喚士は、`leaderAttackTimerSeconds` が0のときに攻撃する。
- 召喚士と通常対象へ同時接触している場合、各タイマーが満了したタイミングで独立して攻撃する。
- 通常対象用タイマーが満了した攻撃では、接触中の全通常対象へそれぞれ既存の `attackDamage` を与える。
- 召喚士用タイマーが満了した攻撃では、既存の `leaderAttackDamage` を与える。
- 自然HP減少、移動、接触減速、攻撃対象の除外条件は変更しない。

## 状態と設定

### `UnitStats`

既存の `attackIntervalSeconds` を通常対象用の攻撃間隔として使用し、キーパー、シーカー、マスターの値をすべて0.5へ変更する。

### `BattleConfig`

- 通常ユニットから召喚士への攻撃間隔として `unitLeaderAttackIntervalSeconds: 1` を追加する。
- `summonedUnitAttackIntervalSeconds` を通常対象用として0.5へ変更する。
- 召喚獣から召喚士への攻撃間隔として `summonedUnitLeaderAttackIntervalSeconds: 2` を追加する。

### `UnitState`

召喚士用の `leaderAttackTimerSeconds` を追加し、生成・復活時に0へ初期化する。

### `SummonedUnitState`

召喚士用の `leaderAttackIntervalSeconds` と `leaderAttackTimerSeconds` を追加する。召喚時には設定値2とタイマー0を設定する。

## エラー処理と互換性

新しいタイマーは既存のゲーム状態生成処理ですべて初期化し、`undefined` のまま戦闘処理へ渡さない。テストで直接 `UnitState` または `SummonedUnitState` を組み立てている箇所も、新しいプロパティを明示的に設定する。

サーバー側のColyseus状態、コマンド形式、描画処理、画像アセットは変更しない。

## テスト

- キーパー、シーカー、マスターの通常対象用攻撃間隔がすべて0.5Cであること。
- 通常ユニットの召喚士用攻撃間隔が1Cであること。
- 召喚獣の通常対象用攻撃間隔が0.5C、召喚士用攻撃間隔が2Cであること。
- 通常ユニットが通常対象へ0.5Cごとに攻撃すること。
- 通常ユニットが召喚士へ1Cごとに攻撃すること。
- 通常対象と召喚士の間で対象を切り替えても、各タイマーが独立して維持されること。
- 召喚獣が通常ユニット、敵召喚獣、エレメントへ0.5Cごとに攻撃すること。
- 召喚獣が召喚士へ2Cごとに攻撃すること。
- 召喚獣が召喚士と通常対象へ同時接触した場合、各タイマーに従って独立して攻撃すること。
- 通常ユニットの生成・復活、および召喚獣の生成時に両タイマーが0となること。
- 両タイマーが0未満にならないこと。
- 既存の攻撃力、射程、倍率、対象除外、接触減速が変わらないこと。

## 対象外

- 攻撃力、射程、移動速度、HP、自然HP減少量の変更。
- 攻撃アニメーション、効果音、HUD表示の追加。
- 通常ユニットの対象選択方式の変更。
- エレメント自身への攻撃能力の追加。
- サーバー同期仕様またはオンライン対戦状態の変更。
