# ユニットカードサイズ変更 設計書

## 目的

戦闘フィールド上のユニットカードを、フィールド寸法に対して指定された大きさへ変更する。
カード上部は、将来追加する攻撃力などの情報表示領域として空けられる構成にする。

## 対象寸法

戦闘フィールドの基準寸法は横 515.2px、縦 368px とする。

### 通常ユニット

- 横幅: フィールド横幅の 10%（51.52px）
- 高さ: フィールド高さの 25%（92px）

### 召喚獣

通常ユニットのカード寸法を縦横ともに 1.3 倍する。

- 横幅: 66.976px
- 高さ: 119.6px

## 描画仕様

- カード外枠を対象寸法に固定する。
- 枠線は対象寸法の外周に一致させる。
- ユニット画像は元画像の縦横比を維持し、カード内の下端へ揃える。
- 画像を変形または切り抜いてカード全体へ引き伸ばさない。
- 画像を配置した結果、カード上部に生じる空き領域は透明な余白として残す。
- 通常ユニット3種は同じカード寸法を使用する。
- 召喚獣は通常ユニットと同じ配置規則を使用し、カード寸法のみ 1.3 倍する。

## 実装方針

カード表示設定に `displayWidth` と `displayHeight` を持たせ、通常ユニットと召喚獣の外枠寸法を明示する。
戦闘シーンは設定された寸法で枠線を描画し、画像は枠内へ縦横比を維持したまま収まるよう縮尺を計算して下寄せする。

寸法値は通常ユニットの基準値と召喚獣の倍率から導出し、描画処理内へ重複した数値を持たせない。

## 対象外

今回の変更では、以下を変更しない。

- HPバーの寸法と配置
- ユニットの選択判定
- 戦闘上の当たり判定
- 初期配置時のユニット間隔
- 攻撃力などの新しい情報表示

## テスト方針

- 通常ユニット3種のカード寸法が 51.52 × 92px であることを確認する。
- 召喚獣のカード寸法が通常ユニットの縦横それぞれ 1.3 倍であることを確認する。
- 画像が縦横比を維持して枠内へ収まり、下端へ揃うための寸法・位置計算を確認する。
- 既存のクライアントテスト、型チェック、ビルドを実行し、他の戦闘画面機能へ影響がないことを確認する。
