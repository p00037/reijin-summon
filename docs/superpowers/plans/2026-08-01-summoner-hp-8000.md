# 召喚士HP 8000化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** プレイヤーとCPUの召喚士の最大HPおよび戦闘開始時HPを2,000から8,000へ変更する。

**Architecture:** 既存の共通設定 `BattleConfig.leaderMaxHp` を単一の情報源として維持し、既定値だけを8,000へ変更する。戦闘状態、HUD、攻撃処理は既存の設定・状態参照をそのまま利用し、HP変更に伴うテスト期待値だけを更新する。

**Tech Stack:** TypeScript 5、Node.js test runner、tsx、Phaser 3.90、Vite

## Global Constraints

- プレイヤーとCPUの召喚士は、どちらも最大HPと戦闘開始時HPを `8000` とする。
- `createDefaultBattleConfig()` の共通設定 `leaderMaxHp` を単一の情報源として維持する。
- プレイヤー用とCPU用の個別HP設定を追加しない。
- 戦闘状態生成後にHPを上書きする処理を追加しない。
- 通常ユニット、エレメンタル、召喚獣のHPを変更しない。
- 攻撃力、攻撃間隔、召喚士への直接攻撃倍率、回復量、回復率、回復間隔を変更しない。
- HPバーの比率計算、表示レイアウト、勝敗判定を変更しない。
- 新しい外部依存関係を追加しない。
- `src/client/public/assets/` 以下にあるユーザーの未コミット変更を編集、削除、ステージ、コミットしない。

---

## File Structure

- Modify: `src/client/src/game/core/battleConfig.ts`
  - 既定の召喚士最大HPを8,000へ変更する。
- Modify: `src/client/src/game/core/battleState.test.ts`
  - 既定設定と両陣営の初期 `maxHp`・`currentHp` が8,000であることを検証する。
- Modify: `src/client/src/game/rules/unitSystem.test.ts`
  - 通常ユニットから召喚士への既存ダメージ期待値を8,000基準へ更新する。
- Modify: `src/client/src/game/rules/summonSystem.test.ts`
  - 召喚獣から召喚士への既存ダメージ期待値を8,000基準へ更新する。召喚獣自身のHPとして使う `2000` は維持する。
- Modify: `src/client/src/game/ui/battleHudModel.test.ts`
  - HUDの最大HP表示と比率期待値を8,000基準へ更新し、上限クランプ用の現在HPを8,000超へ変更する。
