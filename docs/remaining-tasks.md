確認日: 2026-09-23

この文書は、現時点で残っている作業を追跡するための一覧です。実装範囲や詳細な仕様は、着手時に決めます。

## ゲーム機能

- [ ] **各カードの固有アビリティを実装する**  
  現在は兵種共通のアビリティを使用している。カードごとの効果、AP消費、発動条件、表示と対戦同期を追加する。
- [ ] **各カードのスキルを追加する**  
  条件成立時に自動発動するカード固有スキルを追加する。発動条件と効果はカードごとに定義する。
- [ ] **カード構成による召喚獣カスタマイズを追加する**  
  召喚獣を1体選んでデッキと一緒に保存する機能は実装済み。カード構成に応じて召喚獣を変化させる仕組みが残っている。
- [ ] **召喚獣の潜在能力を追加する**  
  現在は種類別の基本性能と一部の専用攻撃を実装済み。潜在能力の発動条件、効果、表示と対戦同期を追加する。
- [ ] **CPUの戦術を強化する**  
  現在は復活、召喚、エレメンタル生成の後、基本的に敵召喚士へ進む。目標選択、兵種別行動、能力の使用判断、編成の変化などを検討する。
- [x] **ユニットの現在位置と移動先マーカーを線で結ぶ**  
  移動中は現在位置からマーカーまで線を表示し、到着・撃破時はマーカーとともに消す。
