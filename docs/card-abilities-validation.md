# カード固有アビリティの実装・検証記録

検証日: 2026-10-01。対象は承認済みのSC001〜SC020（手動アビリティ19種、アビリティなし1枚）。

## 実装結果

- カード別のAP、対象・範囲、INT差補正、時間制効果、解除・吸収、雨、召喚ゲージ回復、エレメント付与を共有ルールへ実装した。
- 通常攻撃・召喚獣攻撃、移動、死亡・復活へ実効値と効果リセットを接続した。戦闘更新は最大1/60秒に分割する。
- オンラインはサーバーで抽選・効果を確定し、効果・エンチャント・雨・連番イベントを配信する。後攻視点で発動者・対象IDと位置を反転する。
- 戦闘画面とデッキ詳細へ固有名・AP・説明を表示する。戦闘画面は天候、候補全員、発動後0.8秒の実対象を表示し、攻撃力表示へ実効ATKを反映する。
- COMの自動使用判断・常時スキルは今回の対象外。

## 実画面・実接続の確認

ローカルの開発画面と、ローカル対戦サーバーへ接続した2つのブラウザクライアントで確認した。検証用の配置・AP・乱数調整はブラウザ内の一時状態で行い、カードの製品データには保存していない。

- SC010の「アビリティなし」、AP表示、ボタン無効化。
- シリカの候補4体から実対象1体、ATK46→32のカード表示。
- クリンの雨100秒、天候表示、説明欄の配置。
- ステラからダライアスへのINT＋3と大津波の補正（INT9対8で456.5、対象HP1225→768.5）。半面の表示と対象判定は自動検証でも確認。
- スペサルティンの建築・同国エレメントへの付与と説明表示。
- 実際のオンライン接続で、両陣営のローズクォーツ付与を同期。ユージアルの候補2体からサーバーが1体を確定し、両クライアントへ同じeventId・反転した発動者/対象を配信、描画側の既読連番も一致。
- デッキ詳細の旧兵種アビリティ説明とINT未使用表記を、現在の固有アビリティ説明へ更新。

## 暫定値と実装上の判断

承認済みの暫定バランス値: タイガーアイ速度0.5倍、ルチル0.4倍、レッドアイ1.5倍、ローズクォーツ1基5％軽減・最大30％、ティアーズ0.28倍。円・オーラ寸法は設計書の初期値を採用し、カード定義から個別調整できる。

- 現在のfeature32で実装した。別worktreeは作成していない。
- `effectiveAttackDamage`は既存のunit先頭引数を維持し、state/configを追加した。
- 相互依存する状態・効果・戦闘の変更と旧テスト移行はまとめて検証した。効果の検証は実際のカード発動を通すテストへ集約した。
- 下部待機枠を復活カードと能力説明へ二分した。復活カードが多数ある場合は表示サイズが縮小する。
- 小刻み更新で、範囲外・移動中の回復進捗は最初の更新から解除する。旧テストが直接代入した回復進捗の持ち越し期待値を更新した。
- Windowsでは作業記録を`tmp/card-abilities`に保持した。

ビルドには既存の大きなJavaScriptチャンク警告が残る。公開環境や実機タブレットでの対戦・表示確認は実施していない。
