# 対人対戦の実装に向けた質問表

作成日: 2026-09-21

## 回答記録（2026-09-21）

- 接続範囲: ローカルで検証後、インターネット公開する。公開時の変更内容も説明する。
- 参加方法: ログイン不要、表示名＋ルーム番号。
- 切断: 試合は進行し、30秒以内に復帰できなければ敗北。
- 相手情報: 戦闘開始時に公開する。
- 対応端末: タブレット優先。既存のタッチ操作を維持する。
- 公開費用・規模: 無料、最大10人を想定する。

以下の質問表は回答前の提案を残したもの。設計案は `superpowers/specs/2026-09-21-online-battle-design.md` に記載する。

## 目的と実施順序

ルーム番号を共有した2人が、現在のカードと召喚獣を使って最後まで対戦できる状態を目指す。

1. 戦闘ルールを両陣営で共通化し、サーバーで実行できる形にする。
2. ルーム作成・参加、デッキ選択、初期配置・準備完了をつなぐ。
3. 移動・能力・召喚・勝敗を同期し、切断時の処理を追加する。
4. 対人戦で検証しながら、固有スキルやバランス調整を追加する。

## 実装方針案

- 既存のColyseusを利用し、サーバーが戦闘状態・ダメージ・勝敗を決定する。
- クライアントは操作要求を送信し、サーバーから受け取る状態を描画する。
- サーバーでデッキのコスト・重複・枚数と、各操作の所有権・実行条件を検証する。
- 両者とも自軍が画面の手前になるよう表示と入力座標を変換する。
- 現在のCPU戦を維持し、共通の戦闘処理を使用する。
- 初回は既存20枚・6種類の召喚獣・兵種共通アビリティで対戦する。
- ランク戦、自動マッチング、観戦、リプレイ、カード固有スキルは初回の範囲に含めない。
- 対戦用サーバーの公開環境は、現在のクライアント用公開設定とは別に用意する。
