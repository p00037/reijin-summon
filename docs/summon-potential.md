# 召喚獣の潜在能力

確認日: 2026-10-04

参照元: [悠久の車輪@Wiki「召喚獣」](https://w.atwiki.jp/ewwiki/pages/32.html)。既存の6体を対象とし、Wikiに数値がない効果は、ユーザー了承済みの仮値を使う。

## 共通の発動条件

- 対戦中、自軍召喚士のHPが最大HPの30%以下で召喚に成功すると自動発動する。HP8000の場合は2400以下。HP0では召喚できない。
- 発動判定は毎回の召喚時に行う。召喚後にHPが減っても、その召喚獣に後付けでは発動しない。
- 潜在能力を適用してから、従来の召喚時攻撃を行う。したがって、潜在ダメージと従来の初撃ダメージはそれぞれ発生する。
- 回復・強化・妨害・ダメージの対象は召喚時点の生存ユニット。エレメンタルを生成中のユニットも含む。味方の復活は戦闘不能ユニットを別に抽出する。
- 通常復活・死亡スキル・潜在能力による復活後、1秒間は潜在能力の対象外とする。この時間はWikiにない仮値で、通常攻撃の無敵時間は追加しない。
- 復活はMPを消費せず、生成中の状態・時間制効果・回復進捗を通常復活と同様に初期化する。復活した味方を同じ潜在能力の回復対象に重ねて含めない。
- 攻撃力・速度・防御補正と引き寄せは既存の時間制効果として管理する。死亡・通常の能力解除で消える。効果時間はINT差で変化させない。同じ召喚獣の同じ効果は累積せず更新する。
- 現在の能力解除は敵ユニットの時間制効果を対象とする。召喚獣自身の強化や、即時のHP・AP・MP変更を巻き戻す効果は追加しない。

## 6体の効果

| 召喚獣 | 実装する効果 | Wikiの明記値・仮設定の区別 |
|---|---|---|
| ラファエル | 生存味方HPを500回復。戦闘不能の味方をHP60%・最大APの半分切り捨てで無料復活 | 500・60%・AP半分はWikiの概算。復活場所は記載がないため自軍召喚士の位置とする |
| ジャックポット | 生存敵ユニットへ600ダメージ、APとAP回復進捗を0にする。敵召喚獣へ基本値600のダメージ | ユニット600・AP0はWiki。召喚獣600は仮値。ユニットへのダメージは防御・ATKに依存しない。召喚士への潜在ダメージはない |
| ユグドラシル | 生存味方のAPをカードごとの最大値にし、AP回復進捗を0にする。MPを3回復。自身の生存中はMP自然回復速度を1.5倍。全体攻撃時に対象の敵を速度0.75倍・3秒間にする | AP最大・MP3はWiki。MP加速の倍率・継続条件と減速の倍率・時間は仮設定 |
| リヴァイアサン | 20秒間、生存味方と自身にATK+15・速度1.125倍・被ダメージ0.95倍。敵ユニットへ400、敵召喚士へ100、敵召喚獣へ基本値100の追加ダメージ | 20秒・ATK+15・400はWiki。速度・防御・召喚士／召喚獣100は仮値 |
| バハムート | 自身のATK+40。生存敵を12秒間、速度0.41で自身の位置へ引き寄せる | ATK+40・12秒はWiki。引き寄せ速度と移動制御は仮設定 |
| デュラハン | 生存敵ATKを17秒間−20。戦闘不能の味方を自軍召喚士の位置でHP満タン・AP0で無料復活 | 17秒・ATK−20・HP満タン・復活場所はWiki。復活時APは記載がないため通常復活と同じ0 |

回復には既存の回復量増加スキルを適用するが、復活HPの設定には適用しない。AP半分は死亡前の保持APではなくカードの最大APを使う。たとえば最大AP5なら2で復活する。アビリティのないカードはAP0を保つ。MPは設定上限を超えず、上限到達時は回復進捗をリセットする。

潜在ダメージはダメージアビリティと同様の処理を使い、ユニットの通常攻撃・召喚獣攻撃用の防御補正を適用しない。敵召喚獣へのダメージには、その召喚獣の被ダメージ倍率を一度適用する。死亡スキルと召喚士の被ダメージによるMP回復は、従来と同様に召喚コマンド内で処理する。

リヴァイアサンの味方強化は召喚獣が先に消滅しても20秒間継続する。自身の強化は20秒で基礎値へ戻る。バハムート自身のATK+40は召喚終了まで続く。これらのATK補正は通常ATKに適用し、別管理の対召喚士攻撃力には加算しない。従来のリヴァイアサンの波動の固定ダメージも変更しない。

ユグドラシルの減速は召喚時に対象を記録し、後から復活した敵には付与しない。対象が一度戦闘不能になった場合は記録から外す。解除しても、次の全体攻撃で生存中の記録対象には再び減速がかかる。最後の攻撃で付与された減速は、ユグドラシルの消滅後も最大3秒間続く。

バハムートの引き寄せ中も移動指示を受け付け、効果終了・解除後にその指示へ戻る。生成中は移動させず、生成自体を中断しない。接触による減速は引き寄せにも適用する。召喚獣消滅後は最後に記録した位置へ、残りの効果時間中引き寄せる。

## 表示と対戦同期

- 編成画面に選択した召喚獣の潜在能力と発動条件を表示する。
- 発動条件を満たすと双方のHPバーが点滅し、召喚獣名の色が変わる。自軍は召喚不可理由がない場合に「潜在能力 発動可能」を表示する。
- 発動時は召喚獣名と「潜在能力発動」、対象位置の光輪を表示する。復活後の対象除外時間中はユニットが点滅する。
- COM戦とオンライン対戦は同じ共有ルールを使う。オンラインでは発動イベント、対象、復活保護、引き寄せ元、時間制効果を全量・差分の両方式で同期する。
- イベントの連番で通知の再表示を防ぐ。後攻視点では陣営・位置・ユニットIDを既存の視点変換で反転する。

## 数値の調整と対象外

数値は `src/shared/src/core/summonPotentialCatalog.ts` にまとめている。Wikiの概算値を原作の厳密な確定値とは扱わず、上記の仮値は実装上の設定とする。
